# Track 1 — Basic Python

You start knowing nothing. You finish able to read a CSV, clean it, train a
small model, and explain what you did.

## The order matters

Each lesson uses what the one before it built. Lesson 07 assumes you can write
a loop; lesson 09 assumes you can read a list. Skipping ahead feels faster for
about twenty minutes.
